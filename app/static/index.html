단면 크기 원천 불일치

                
              

              

                텍스트 = 단면 아래 「크기」 + 부재표기 괄호치수(member). 치수선 = 단면 주변 치수 라벨. 단면 = 읽은 상·하 가로선 거리 기반 W/H. 서열에 없는 값만 서로 차이 나면 행으로 표시됩니다.
              

              

            

          

          

            

              
부재별 표

              

                
                
              

            

            

            

              

                
                  부재별표 디버그 (텍스트) — 펼치기
                
                

                  
                

                

              

            

          

          

            

              디버그 패널
              

            

          

          

            

            

              
보·기둥·벽체·슬라브 탭에서 「일람 추출 실행」하면 여기에 표로 표시됩니다.

            

          

        

      

      

        

          

            
              보 가로묶음(행 클러스터) 디버그 (닫힘/펼침)
            
            

              
              
              

                
                  보 flat 단면 단계 디버그(체크 시 개별 색 박스)
                
                

                  우측 「단면 오버레이」켜고, 보 탭·flat 단면 도면에서만 표시. 번호는 클러스터 순(#1…).
                

                

                  
                  
                  
                  
                  
                  
                  
                

              

              
            

            

              R0,R1…은 `y_tolerance` 기준으로 같은 줄로 묶인 목록입니다. 행을 클릭하면 해당 eid들이 캔버스에서 하이라이트됩니다.
            

            

            

            

          

          

            
              보 단면 읽기 과정 디버그 (원 · 단면 · 선분)
            
            

              느슨 창 원 후보 → 단면 윤곽·박스 → 띠근(x/y) 등 단계별로 정리합니다. 채팅·이슈에 붙일 때 아래 「전체 복사」를 쓰세요.
            

            

              
            

            

          

          

            
              보 flat 하단 텍스트 매칭 디버그
            
            

              

                단면 아래 텍스트 hit/match, 연결 대상 텍스트(레이어/etype), 치수선 필터 상태를 표시합니다.
              

              
            

            

          

          

            
              보 flat 하단 텍스트 원본(hits)·라벨/값 진단
            
            

              

                단면별 belowHits 원본 목록(역할 라벨 포함)과, `크기`/`상부근` 라벨이 있을 때 실제로 어떤 값이 선택되는지(또는 왜 못 고르는지)를 보여줍니다.
              

              
            

            

          

          

            
              보 flat 선분(묶임/제외) 디버그
            
            

              

                단면 bbox 내부 선분 수, 원 클러스터 근접 선분 채택/제외(겹침/긴직선) 통계를 표시합니다.
              

              
            

            

          

        


        


        


        


        

          
            보 단면 박스 중첩 디버그 (선택 기반)
          
          

            

              선택된 부재/부위(eid)에 해당하는 단면 박스 후보 중, 겹침(OVERLAP)이 큰 것만 보여줍니다.
